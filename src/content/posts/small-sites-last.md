Every moving part is a future outage. A folder of HTML files has none.

## What you give up

No comments, no logins, no admin screen. You edit a text file and push. For a personal blog that is not a sacrifice, it's the feature.

## What you keep

- Pages that load instantly
- Hosting that costs almost nothing
- Content in plain Markdown you can move anywhere

```bash
npm install
npm run build
# upload dist/ anywhere
```
